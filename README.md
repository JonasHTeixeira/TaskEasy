## Sobre o Projeto

O **TaskEasy** é um sistema simples de gerenciamento de tarefas pessoais. Seu objetivo é ajudar usuários a organizar atividades do dia a dia em um único lugar, acompanhando o que precisa ser feito e o que já foi concluído.

**Problema:** muitas pessoas anotam compromissos e tarefas em diferentes lugares ou acabam esquecendo atividades importantes.

**Solução:** oferecer uma ferramenta simples na qual o usuário possa cadastrar tarefas, definir prazos, consultar sua lista, editar informações e marcar atividades como concluídas.

## Funcionalidades principais

- Cadastrar uma tarefa com título e descrição.
- Definir uma data de vencimento.
- Visualizar a lista de tarefas.
- Editar ou excluir uma tarefa.
- Marcar uma tarefa como concluída.
- Filtrar tarefas pendentes e concluídas.

## Escopo inicial (MVP)

O MVP acadêmico contempla o fluxo básico de organização de tarefas:

`Acessar o sistema -> Cadastrar tarefa -> Visualizar tarefas -> Editar/Excluir -> Marcar como concluída`

O projeto não contempla, nesta primeira versão, compartilhamento de tarefas, notificações, calendário integrado ou colaboração entre usuários.
